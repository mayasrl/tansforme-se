# Projeto de Cidadania e Políticas Públicas

Projeto em desenvolvimento com foco em facilitar o acesso a informações sobre cidadania, direitos e políticas públicas.

## Sobre o projeto

A proposta surgiu a partir da dificuldade que muitas pessoas têm para encontrar informações simples e confiáveis sobre seus direitos, deveres e sobre o funcionamento do governo.

O projeto busca apresentar essas informações de forma clara, objetiva e acessível.

## Objetivo

Ajudar na formação de cidadãos mais conscientes e informados.

## Público-alvo

O projeto é voltado principalmente para:

* Jovens;
* Pessoas de baixa renda;
* Pessoas em situação de vulnerabilidade social;
* Pessoas com pouca familiaridade com política e direitos;
* Imigrantes;
* Pessoas mais velhas.

## Conteúdos previstos

* Direitos de todo cidadão;
* Direitos do trabalhador;
* Direitos das pessoas com deficiência;
* Direitos dos estudantes;
* Direitos dos imigrantes;
* Funções das instituições e dos cargos públicos;
* Dúvidas frequentes sobre cidadania.

## MVP

A primeira versão terá como foco:

* Direitos de todo cidadão;
* Funções institucionais do país.

Os demais conteúdos poderão ser adicionados posteriormente.

## Design

A proposta é criar uma interface:

* Moderna;
* Simples;
* Intuitiva;
* Responsiva;
* Acessível;
* Fácil de utilizar pelo celular.

A identidade visual ainda será definida.
